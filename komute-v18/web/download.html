Komute

Quezon City commute guide for Android

Download the app (APK) About 60 KB · Android 7 or newer
  1. Open the downloaded Komute.apk. If Android asks, allow installing from this browser.
  2. If Google Play Protect says "App blocked", tap More details, then Install anyway.
  3. Open Komute. The first start can take up to a minute while the server wakes up.
Updating from an older Komute? If the install says "package conflicts", uninstall the old Komute first.
